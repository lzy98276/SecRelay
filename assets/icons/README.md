# SecRelay 图标规范

## 文件

| 文件 | 用途 |
|---|---|
| `secrelay.svg` | **唯一源文件**。256 视图框、透明底、带投影。所有位图都必须由它派生 |
| `secrelay-mono.svg` | 单色版：文档内联、单色印刷、将来的系统托盘 |
| `png/secrelay-*.png` | 文档与官网直接用的位图导出（透明底） |

**不要手改派生位图。** 改了矢量就重新导出，否则两者会不一致。

## 设计语言

本图标与 **SecRandom**（随机点名）属于同一套视觉语言，不是各画各的：

- 透明底，不套白色方块、不套圆角卡片
- 扁平几何，无描边、无内渐变；立体感只靠**折面双色**做出来
- 只用一个非蓝强调色，且**压在右下、溢出主体轮廓**
- 主体与强调符号之间靠柔和投影拉开，不加硬白色描边
- 折角统一磨圆

**两处与 SecRandom 不同，是刻意的：**

1. SecRandom 是满幅白底，SecRelay 用**透明底** —— 因为 SecRelay 的主要用途是带深色模式的文档与官网。
2. 强调色不同：SecRandom 用 `#36AA75`（墨绿），SecRelay 用 `#F2A33C`（琥珀）。主蓝与浅蓝则**直接取自 SecRandom 的实测值**，家族感主要靠这两个蓝承载。

## 几何

画布 256×256，内容外框 **x 23.5–233、y 48.5–205**（宽 209.5、高 156.5），居中。

留白：左右各约 23（9%），上下各约 49（19%）。横向比纵向满，是"左上飞机 → 右下箭头"这条对角动势决定的。

形体由这几个数决定，**改数不要手改路径点**：

| 旋钮 | 当前值 | 说明 |
|---|---|---|
| 机身长 | 126 | 机头在 (167,160)，沿 25° 航向向后 |
| 航向俯冲角 | 25° | 太小读起来像悬停，太大会让远近两翼一高一扁、变成飞镖 |
| 翼展 | 120 | 后缘从 (78,52) 到 (27,161) 的完整直线 |
| 缺口切深 | 30% | 楔形缺口尖端距机头的距离 ÷ 机身长 |
| 缺口宽度 | **18%** | 缺口占后缘的比例 |

**缺口是这个图标里最容易做砸的一处，务必照抄现版的做法：后缘保持完整直线，中间只开一道窄而深的楔形缺口。**

两种错误做法及后果：

- **整条后缘收成一个 V**（把后缘从 A 到 B 收尖成一个点）→ 两翼变成两条细条，整架飞机读起来像飞镖／闪电。这是本项目返工最多的一处，前后废了 13 版草稿。
- **不开口**（后缘整条直线，两块折面靠一条直线分色）→ 读起来是一个平面的三角形箭头，不再有"折纸"的结构。

判断标准很简单：**看两翼是否各自都还是一整块。** 把 `secrelay.svg` 导到 64px 看，两片翼应该是两块实心色块中间夹一道缝；如果看到的是两条细线，就是踩了第一个坑。

缺口宽度越窄两翼越贴合、越含蓄；18% 是"保住两片翼"和"不看起来像被剪掉一块"之间的取值。

## 最小尺寸

| 尺寸 | 可用性 |
|---|---|
| ≥ 64px | 完整细节，推荐 |
| 32–48px | 可用，但箭头会细到接近 2px |
| < 32px | **不要直接用**。需要的话另做简化版（去掉箭头，只留飞机） |

箭头宽度是 68 个画布单位（26.6%），这是小尺寸下先糊掉的部分。

## 导出

需要的档位：**512 / 256 / 128**（透明底 PNG），分别给官网、README 头图 @2x、文档内联 @2x。

导出必须是**透明底**：

```bash
# 推荐：resvg（跨平台、无浏览器依赖，可进 CI）
resvg --width 512 --height 512 assets/icons/secrelay.svg assets/icons/png/secrelay-512.png
resvg --width 256 --height 256 assets/icons/secrelay.svg assets/icons/png/secrelay-256.png
resvg --width 128 --height 128 assets/icons/secrelay.svg assets/icons/png/secrelay-128.png
```

仓库里现有的 `png/` 是用无头 Edge 截出来的（这台机器上没有 resvg）。那个方式依赖 Windows + Edge，**不适合进 CI**，确定导出管线后应换成 resvg 或 sharp，并把"派生位图与矢量不一致"做成可检查项。

## 使用禁忌

- **不要加背景方块或圆角卡片。** 本图标是透明底，设计上要能在深色和浅色文档背景上直接用；套上白底会在深色 README 里变成一块刺眼白块。
- **不要拉伸。** 视图框是正方形，按等比缩放。
- **不要把飞机和箭头拆开单用。** 箭头离开飞机就不再表示任何东西；单色版里两者靠 62% 不透明度差维持主次。
- **不要在 32px 以下直接用**，见上表。
- **不要改缺口。** 见"几何"一节的两种错误做法。
